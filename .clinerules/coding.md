# Developer Practices

1. Test-driven development - when I ask for something, write a integration or unit test
2. Less is more - keep it simple and stupid for me to debug when necessary.
3. Update docs (README/memory-bank) after every iteration and pictures/diagrams + code snippets are the most valuable over walls of AI-generated text
4. Use US-english (color vs colour, scrutinize vs scrutinise, etc.), no unicode like ∆, and no icons like 🛠
5. Aggresive type hints - I want basically everything functional and statically typed when possible.
6. PIN VERSIONS DOWN... never leave packages/modules/etc. unpinned and only change if you have run tests and passed when needed for a new feature/bugfix
7. Use & for chaining commands in shell not &amp
